# e-Govアカウントの登録方法

e-Govアカウントの登録手順をご案内します。
e-Gov が提供するサービスは、以下のアカウントでもログインできます。
これら外部認証サービスのアカウントを利用する場合は、e-Govアカウント仮登録手続以降の手順は不要です。各サービスの案内に従ってアカウントを取得してください。
・GビズID
・マイナンバーカード
・Microsoftアカウント
・Googleアカウント

（注意）
e-Govアカウントでは、電子メールアドレスの大文字・小文字を区別しません。
アカウント登録時に入力した電子メールアドレスは、全て小文字にした状態で管理されます。例えば、次のようなメールアドレスはどちらも同一メールアドレスとして取り扱われます。
【例】e-gov.2020＠e-gov.go.jp　　e-Gov.2020@e-gov.go.jp

メールアドレスのローカルパート(@マークより前)に利用可能な文字は以下の通りです。
「半角英数字」、「-（ハイフン）」、「.（ピリオド」）、「_（アンダーバー）」

この取扱いは、GビズID等とのID連携を利用する場合も同様となります。

## e-Govアカウント仮登録手続

e-Govアカウント仮登録入力画面へアクセスし、メールアドレスを入力してください。

［内容を確認］をクリックします。

入力したメールアドレスが表示されるので、確認後に［登録］をクリックします。
入力したメールアドレスに、本登録を行うためのリンクが記載されたメールが送信されます。

受付日時から1時間以内にメール本文内のリンクから本登録ページにアクセスし、e-Govアカウントの本登録を行います。

仮登録後に届いたメール本文内のリンクから本登録ページにアクセスし、e-Govアカウントの本登録手続を行います。

必要事項を入力し、［内容を確認］をクリックします。

入力したメールアドレスが表示されるので、確認後に［登録］をクリックします。
入力したメールアドレスに、利用者登録完了のメールが送信されます。

e-Govアカウントの登録手順は以上になります。
完了画面で表示される各ボタンは、仮登録を開始したサービスにより異なります。
登録したアカウントでe-Govが提供するサービスにログインしてください。
