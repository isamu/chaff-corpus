## 概要・内容

来年度小学校・中学校・義務教育学校に入学されるお子さんについて、お住まいの区役所が住民基本台帳の住所により就学する学校を指定し、就学通知書を発送します。就学通知書は、12月末日までに送付されます。

詳細につきましては、【小学校・中学校・義務教育学校の入学】をご覧ください。
