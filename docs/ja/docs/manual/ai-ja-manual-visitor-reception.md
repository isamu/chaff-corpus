# 来客受付の手順

この手順書は、本社1階の受付でお客様をお迎えするときの流れをまとめたものです。受付当番になった人は、初日の前に一度目を通しておいてください。迷ったときは、無理に自分で判断せず、総務の担当者に相談して大丈夫です。

## 受付当番の時間

受付は平日9:00〜18:00です。当番は午前（9:00〜13:00）と午後（13:00〜18:00）に分かれています。昼休みの12:00〜13:00は、午前の当番が残って受付を続け、13:00に午後の当番と交代します。

## お客様が来たら

1. 立ち上がって「いらっしゃいませ」と声をかけます。座ったままの対応は避けてください。
2. お客様のお名前、会社名、訪問先の社員の名前を伺います。
3. 来客予定表（受付の共有フォルダにある「本日の来客」）に、そのお客様の名前があるか確認します。
4. 入館証を渡し、来客受付簿にお名前・会社名・入館時刻を書いていただきます。
5. 訪問先の社員に内線で連絡し、「〇〇様がお見えです」と伝えます。
6. 社員が迎えに来るまで、ロビーのソファでお待ちいただきます。

## 予定表に名前がないとき

予定表にない来客でも、珍しいことではありません。社員が予定表への登録を忘れていることもよくあります。訪問先の社員に内線で確認し、「お通ししてください」と言われたら、通常と同じ手順で受付してください。

社員に連絡がつかないときは、同じ部署の別の人に確認します。それでもわからない場合は、お客様にお詫びしてロビーでお待ちいただき、総務の担当者を呼んでください。

## 気をつけること

- **入館証は必ず返していただく**：お客様が帰るときに入館証を返していただき、受付簿に退館時刻を書きます。返却がないまま帰られたときは、総務に連絡してください。
- **お客様を一人で執務フロアに通さない**：エレベーターの場所を聞かれても、必ず社員の迎えを待っていただきます。
- **電話番号や社員の予定を教えない**：「〇〇さんは今日いますか」と聞かれても、確認してからお答えすると伝え、本人に確認します。

## 宅配便・郵便物

宅配便は受付で受け取り、宛名の部署の棚に入れます。代金引換や着払いのものは受け取らず、宛名の社員に連絡してください。

## 困ったとき

総務の受付担当（内線 1200）に連絡してください。急な体調不良のお客様がいる、不審な人がいるなどのときは、まず総務に電話し、必要なら迷わず119番・110番に通報してください。
