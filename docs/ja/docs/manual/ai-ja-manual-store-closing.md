# 閉店作業マニュアル

閉店作業は、遅番のスタッフ2名で行います。必ず2名で行い、1人で店内に残らないでください。作業はおおむね45分で終わります。最後にチェックリストに記入し、責任者の印をもらってから退勤してください。

## 1. 閉店前（20:30〜21:00）

1. 20:30に店内放送で閉店30分前のお知らせを流します（レジ横のタブレットで「閉店案内」を押す）。
2. 揚げ物ケースの残りを確認し、値引きシールを貼ります。シールの金額はケースの横に貼ってある表を見てください。
3. 21:00に入口の自動ドアを「出口のみ」に切り替えます。スイッチはサービスカウンター裏の壁にあります。

## 2. レジ締め（21:00〜）

1. 最後のお客様が出たら、レジで「精算」→「点検」の順に押し、レシートを出します。
2. ドロアーの現金を数え、金種表に記入します。釣り銭用として、1万円分（千円札5枚、百円玉30枚、十円玉など）を翌日分に残します。
3. 点検レシートの金額と実際の現金が合っているか確認します。**1円でも合わない場合は、もう一度2人で数え直してください。**それでも合わない場合は、差額を金種表に書き、責任者に連絡します。自分たちで埋め合わせたりしないでください。
4. 売上金は入金袋に入れ、金種表と点検レシートを一緒に入れて事務所の金庫に入れます。

## 3. 売り場

1. 冷蔵ケースのナイトカバーを下ろします。
2. 惣菜・パンの売れ残りは、廃棄登録をしてから専用のゴミ箱に捨てます。廃棄登録はハンディ端末の「廃棄」メニューから行います。**登録を忘れると在庫がずれるので、必ず捨てる前に登録してください。**
3. 床に落ちている商品やゴミを拾い、モップがけが必要な場所（特に冷蔵ケースの前）を拭きます。

## 4. バックヤード

1. 揚げ物のフライヤーの電源を切ります。油の交換日（月・木）は、油が冷めてから交換するので、早番に申し送りをしてください。閉店時に熱い油を扱うのは禁止です。
2. 生ゴミと段ボールを裏口の集積場に出します。
3. 冷凍庫・冷蔵庫の温度を確認し、チェックリストに記入します（冷凍庫はマイナス18℃以下、冷蔵庫は10℃以下）。基準を超えていたら、すぐに責任者に連絡してください。

## 5. 最終確認と施錠

1. トイレに人が残っていないか確認します。
2. 店内の照明を消します（バックヤードの分電盤横のスイッチ。「常夜灯」と書いてあるものは消さない）。
3. 警備システムをセットします。暗証番号は責任者から口頭で聞いてください。紙に書いて置いておかないこと。
4. 裏口から出て施錠し、2人でドアが閉まっていることを確認します。

## 困ったとき

- 現金が合わない、温度が基準を超えている、警備システムがセットできない：責任者の携帯に電話（番号は事務所のホワイトボード）
- 責任者につながらない：エリアマネージャーに電話
- 不審者がいる、急病人がいる：迷わず110番・119番
