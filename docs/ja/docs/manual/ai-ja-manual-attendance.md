# 勤怠管理システム 操作マニュアル（従業員向け）

## 1. はじめに

本マニュアルは、勤怠管理システムを利用して出退勤の打刻、各種申請を行う方法について説明するものです。全従業員は本マニュアルに従って、正確な勤怠の記録を行ってください。

## 2. ログイン方法

1. パソコンまたはスマートフォンのブラウザで、社内ポータルの「勤怠管理」を開きます。
2. 社員番号とパスワードを入力し、「ログイン」をクリックします。
3. 初回ログイン時は、パスワードの変更画面が表示されます。8文字以上で、英字と数字を組み合わせた新しいパスワードを設定してください。

> **注意**：パスワードを5回続けて間違えると、アカウントがロックされます。ロックされた場合は、総務部までご連絡ください。

## 3. 出退勤の打刻

### 3.1 出勤時

1. ログイン後、ホーム画面の「出勤」ボタンをクリックします。
2. 「出勤を記録しました」と表示されれば完了です。

### 3.2 退勤時

1. ホーム画面の「退勤」ボタンをクリックします。
2. 「退勤を記録しました」と表示されれば完了です。

### 3.3 休憩

休憩時間は、所定の休憩時間（12:00〜13:00）が自動で記録されます。所定の時間以外に休憩を取った場合は、「4. 打刻の修正」の手順で休憩時間を修正してください。

### 3.4 在宅勤務の場合

在宅勤務の日も、自宅から同じ手順で打刻してください。出勤ボタンをクリックすると勤務場所を選ぶ画面が表示されるので、「在宅」を選択します。

## 4. 打刻の修正

打刻を忘れた場合や、誤って打刻した場合は、以下の手順で修正を申請してください。

1. メニューから「勤怠一覧」を開きます。
2. 修正したい日付をクリックします。
3. 「修正申請」をクリックし、正しい時刻と修正の理由を入力します。
4. 「申請」をクリックします。

修正申請は所属長の承認後に反映されます。打刻漏れは、原則として翌営業日までに申請してください。

## 5. 休暇の申請

1. メニューから「休暇申請」を開きます。
2. 休暇の種類（年次有給休暇、特別休暇など）を選択します。
3. 取得する日付と、全日・午前半休・午後半休のいずれかを選択します。
4. 必要に応じて備考を入力し、「申請」をクリックします。

年次有給休暇は、原則として取得日の3営業日前までに申請してください。急な体調不良などで当日に休む場合は、始業時刻までに所属長へ電話またはチャットで連絡し、出勤後に申請を行ってください。

有給休暇の残日数は、ホーム画面の右上で確認できます。

## 6. 残業の申請

所定の終業時刻（18:00）を超えて勤務する場合は、事前に残業申請を行ってください。

1. メニューから「残業申請」を開きます。
2. 日付、予定終了時刻、業務内容を入力します。
3. 「申請」をクリックします。

事前申請のない残業は、原則として認められません。やむを得ず事前に申請できなかった場合は、翌営業日までに事後申請を行い、所属長にその理由を説明してください。

## 7. 月末の締め処理

毎月の最終営業日に、その月の勤怠を確認して締め処理を行います。

1. 「勤怠一覧」を開き、打刻漏れや未承認の申請がないことを確認します。
2. 問題がなければ、画面下部の「月次確定」をクリックします。

月次確定の期限は、翌月3営業日目の17:00です。期限までに確定されていない場合、給与の計算に影響が出ることがありますのでご注意ください。
