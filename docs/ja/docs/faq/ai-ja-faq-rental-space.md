# レンタルスペース「ことのは」よくある質問

## 予約について

**何日前から予約できますか？**
利用日の3か月前の1日から予約できます。たとえば7月10日に使いたい場合は、4月1日から予約できます。

**当日の予約はできますか？**
空きがあれば、利用開始の1時間前までウェブで予約できます。それ以降は電話でお問い合わせください。

**キャンセル料はかかりますか？**
利用日の7日前まではかかりません。6日前から前日までは料金の50%、当日は100%をいただきます。日程の変更は、空きがあれば前日まで無料です。

## 料金について

**料金はいくらですか？**
1時間あたり、平日2,200円、土日祝3,300円です（税込）。利用は2時間からで、以降は30分単位で延長できます。料金には机・椅子・Wi-Fi・ホワイトボードの利用が含まれています。

**支払い方法は？**
予約時にクレジットカードでお支払いください。請求書払いは、法人のお客さまで月2回以上ご利用の場合にご相談に応じます。

## 設備について

**何人まで入れますか？**
着席で16人、立食なら24人までです。机は2人掛けが8台あり、配置は自由に変えられます。使い終わったら、元の配置（部屋の写真を壁に貼っています）に戻してください。

**プロジェクターはありますか？**
あります（無料）。HDMIケーブルを用意しています。USB-CやMini DisplayPortの方は、変換アダプタをお持ちください。

**キッチンは使えますか？**
電子レンジ、電気ケトル、冷蔵庫が使えます。コンロはありません。調理をともなう料理教室などには向いていないので、ご了承ください。

**飲食はできますか？**
できます。お酒も可ですが、22時以降は近隣の方への配慮のため、大きな声を出さないようお願いしています。ゴミはお持ち帰りください。持ち帰りが難しい場合は、1袋500円で処分を承ります。

## 当日の利用について

**鍵はどうやって受け取りますか？**
入口のキーボックスを使います。暗証番号は、利用日の前日にメールでお送りします。開始時刻より前には入室できないので、準備の時間も含めて予約してください。

**退室時にすることはありますか？**
机と椅子を元に戻し、エアコンと照明を消して、鍵をキーボックスに返してください。終了時刻を過ぎると、15分ごとに延長料金がかかります。

## その他

**駐車場はありますか？**
ありません。近くのコインパーキング（徒歩2分）をご利用ください。

**物販やセミナーで使ってもいいですか？**
大丈夫です。ただし、宗教の勧誘やネットワークビジネスを目的としたご利用はお断りしています。

ほかにご不明な点は、お問い合わせフォームからご連絡ください。2営業日以内にお返事します。
