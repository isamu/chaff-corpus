# pdfmerge-cli

複数のPDFファイルを1つに結合するための、シンプルなコマンドラインツールです。

## 特徴

- 複数のPDFファイルを指定した順番で結合
- ディレクトリ内のPDFをファイル名順にまとめて結合
- ページ範囲を指定して、必要なページだけを抽出・結合
- しおり（ブックマーク）を元のファイル名で自動作成
- Windows / macOS / Linux に対応

## 動作環境

- Python 3.9 以上

## インストール

```bash
pip install pdfmerge-cli
```

ソースからインストールする場合：

```bash
git clone https://github.com/yourname/pdfmerge-cli.git
cd pdfmerge-cli
pip install .
```

## 使い方

### 基本的な使い方

結合したいファイルを順番に指定し、`-o` で出力ファイル名を指定します。

```bash
pdfmerge a.pdf b.pdf c.pdf -o merged.pdf
```

### ディレクトリ内のPDFをまとめて結合

ディレクトリを指定すると、その中のPDFファイルをファイル名順に結合します。

```bash
pdfmerge ./invoices -o invoices_all.pdf
```

ファイル名に含まれる数字は数値として並べ替えます（`2.pdf` は `10.pdf` より前になります）。

### ページ範囲を指定する

ファイル名の後ろに `:` とページ範囲を付けると、そのページだけを結合します。

```bash
# report.pdf の1〜3ページと、appendix.pdf の5ページ目だけを結合
pdfmerge report.pdf:1-3 appendix.pdf:5 -o output.pdf
```

範囲はカンマで区切って複数指定できます（例：`doc.pdf:1-3,7,10-12`）。

### オプション一覧

| オプション | 説明 |
| --- | --- |
| `-o`, `--output` | 出力ファイル名（必須） |
| `--no-bookmarks` | しおりを作成しない |
| `--sort name\|mtime` | ディレクトリ指定時の並び順（ファイル名順／更新日時順）。初期値は `name` |
| `--password` | パスワード付きPDFを開くためのパスワード |
| `-f`, `--force` | 出力ファイルが既に存在する場合に上書きする |
| `-q`, `--quiet` | 処理中のメッセージを表示しない |
| `-h`, `--help` | ヘルプを表示する |

## 注意事項

- パスワードで保護されたPDFは、`--password` でパスワードを指定しないと結合できません。複数のファイルで異なるパスワードが設定されている場合は、あらかじめ個別に解除してください。
- フォームの入力欄や電子署名は、結合後に正しく動作しないことがあります。
- 出力ファイルと同じ名前のファイルが既にある場合は、`-f` を付けない限りエラーになります。
