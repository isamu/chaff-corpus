# shift-maker

飲食店やコンビニなど、少人数の店舗向けのシフト表自動作成ツールです。スタッフの希望（出られる日・出られない日）と、日ごとの必要人数を書いたCSVを読み込み、条件を満たすシフト表をExcelファイルで出力します。

店長が毎月スプレッドシートと格闘していた作業を、なるべく短くするために作りました。

## できること

- スタッフごとの「出勤可能日」「出勤不可日」「希望日」を考慮してシフトを作成
- 曜日・時間帯ごとの必要人数を満たすように割り当て
- 週あたりの最大勤務日数、連勤の上限を設定可能
- 「この2人は同じ時間帯に入れない／必ず一緒に入れる」といった組み合わせの指定
- 勤務日数ができるだけ均等になるように調整
- 結果をExcel（.xlsx）で出力。そのまま印刷して掲示できます

## 必要なもの

- Python 3.10 以上
- 依存ライブラリ：`ortools`、`openpyxl`、`pandas`

## インストール

```bash
git clone https://github.com/example/shift-maker.git
cd shift-maker
pip install -r requirements.txt
```

## 使い方

### 1. 入力ファイルを用意する

`samples/` フォルダにあるサンプルをコピーして編集するのが簡単です。

**staff.csv**（スタッフと希望）

```csv
name,max_days_per_week,unavailable,preferred
佐藤,4,2027-01-03;2027-01-04,
鈴木,5,,2027-01-10
田中,3,2027-01-15,
```

- `unavailable`：出られない日（`;` 区切り）
- `preferred`：できれば入りたい日（`;` 区切り）

**demand.csv**（必要人数）

```csv
weekday,slot,required
mon,morning,2
mon,evening,3
sat,morning,3
sat,evening,4
```

### 2. 実行する

```bash
python -m shift_maker --staff staff.csv --demand demand.csv --month 2027-01 -o shift_2027-01.xlsx
```

数秒〜数十秒で `shift_2027-01.xlsx` が作成されます。

### 3. 設定を変える

連勤の上限や組み合わせの指定は `config.yaml` に書きます。

```yaml
max_consecutive_days: 5
not_together:
  - [佐藤, 鈴木]
always_together:
  - [田中, 高橋]   # 新人の田中さんは高橋さんと一緒に
```

## 条件を満たせないとき

希望が厳しすぎて必要人数を満たせない場合は、エラーにはせず、足りない日と時間帯を一覧で表示します。

```
⚠ 必要人数を満たせない枠があります
  2027-01-09 (土) evening: 必要 4人 / 割り当て 3人
```

この場合は、該当日に出られる人に個別に相談するか、`demand.csv` の人数を見直してください。

## 制限事項

- 1日2枠（朝・夜など）までを想定しています。3枠以上にも一応対応していますが、テストは十分ではありません。
- スキル（レジができる、調理ができるなど）を考慮した割り当てには、まだ対応していません。
- 祝日は自動で判定しません。祝日の必要人数を変えたい場合は、`demand.csv` に日付で指定してください。
