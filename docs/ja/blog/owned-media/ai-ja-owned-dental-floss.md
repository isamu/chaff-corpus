# 歯みがきだけでは落としきれない？　フロスと歯間ブラシの使い分け

こんにちは。さくら歯科クリニック 歯科衛生士の中野です。

「毎日しっかり歯をみがいているのに、むし歯や歯ぐきの腫れを指摘された」という方は少なくありません。実は、歯ブラシだけで落とせる汚れは、全体の6割ほどといわれています。残りの汚れの多くがたまっているのが、歯と歯の間です。

今回は、歯の間の汚れを落とす「デンタルフロス」と「歯間ブラシ」について、どう使い分ければよいかをご紹介します。

## フロスと歯間ブラシ、どう違うの？

### デンタルフロス

細い糸で、歯と歯がぴったりくっついている部分の汚れを落とします。歯の間にすき間がほとんどない、若い方や歯ぐきが健康な方に向いています。

指に巻きつけて使う「糸巻きタイプ」と、持ち手がついた「ホルダータイプ」があります。初めての方は、ホルダータイプのほうが扱いやすいでしょう。

### 歯間ブラシ

小さなブラシで、歯と歯の間のすき間を掃除します。年齢とともに歯ぐきが下がって、歯の間にすき間ができてきた方や、ブリッジが入っている方に向いています。

サイズがいくつもあるので、すき間に合ったものを選ぶことが大切です。きつすぎるものを無理に入れると、歯ぐきを傷つけてしまいます。

## 使うときのポイント

- **フロス**は、歯の側面に沿わせるように、ゆっくりと上下に動かします。歯ぐきに勢いよく当てないように気をつけましょう。
- **歯間ブラシ**は、歯ぐきに対してまっすぐ、ゆっくり差し込み、2〜3回前後に動かします。
- どちらも、**1日1回、夜の歯みがきのとき**に使うのがおすすめです。寝ている間は唾液が減り、細菌が増えやすいためです。

使い始めは、少し血が出ることがあります。歯ぐきに炎症があるサインで、続けているうちに1〜2週間ほどで治まることがほとんどです。ただし、2週間以上たっても出血が続く場合は、一度ご相談ください。

## どちらを使えばいいか迷ったら

歯の間のすき間の大きさは、場所によっても違います。前歯はフロス、奥歯は歯間ブラシ、というように使い分けている方もいらっしゃいます。
