# 祖母の台所

祖母の家の台所は、北向きで、昼間でも少し薄暗かった。

流しの上に小さな窓がひとつあって、そこから裏の家の柿の木が見えた。冬になると、窓ガラスの内側がいつも白く曇っていた。祖母はその曇りを布巾でさっと拭いてから、外を見て「今日は冷えるねえ」と言うのが癖だった。

小学生のころ、夏休みと冬休みは、ほとんど祖母の家で過ごしていた。両親が共働きで、ほかに預け先がなかったからだ。祖母の家には子どもが遊ぶようなものは何もなかったので、私はたいてい台所の隅の丸椅子に座って、祖母が料理をするのを眺めていた。

祖母は、計量カップも計量スプーンも使わなかった。醤油は瓶から直接、鍋の縁をぐるりと回すように入れる。砂糖は、手のひらにざっと出してから落とす。一度、「どれくらい入れたの」と聞いたことがある。祖母は少し考えて、「このくらい」と、また手のひらを見せた。それ以上の答えはなかった。

台所には、いつも何かの匂いがしていた。煮干しでとった出汁の匂い、ぬか床の匂い、冬は干した大根の匂い。あの家を思い出すとき、最初に浮かぶのは部屋の様子ではなく、その匂いのほうだ。

祖母がよく作ってくれたのは、ひじきの煮物だった。子どものころの私は、正直それほど好きではなかった。黒くて地味だし、甘いのかしょっぱいのかよくわからない。それでも祖母は、私が来るたびに小鉢に盛って出してくれた。残すと悪い気がして、いつも黙って食べていた。

祖母が亡くなって、もう十年以上になる。家はとうに人の手に渡り、あの台所がどうなったのかは知らない。

去年の冬、ふと思い立って、ひじきの煮物を作ってみた。インターネットでレシピを調べて、書いてあるとおりに計って作った。できあがったものは、ちゃんとおいしかった。でも、祖母の味とは違った。どこが違うのかと聞かれても、うまく説明できない。たぶん、醤油を回し入れるときのあの「このくらい」が、私にはわからないのだと思う。

それ以来、ときどきひじきを煮ている。計量スプーンは使わずに、手のひらに砂糖を出してみたりもする。まだ一度も、あの味にはなっていない。

それでも、鍋から上がる湯気の中に、ほんの少しだけ、あの薄暗い台所の匂いがすることがある。そういう日は、窓の曇りを拭いて、外を見たくなる。
