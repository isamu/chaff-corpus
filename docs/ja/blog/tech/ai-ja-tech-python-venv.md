# 【初心者向け】Pythonの仮想環境（venv）の使い方をわかりやすく解説

Pythonを勉強し始めると、「仮想環境を作りましょう」という説明をよく目にします。でも、なぜ必要なのか、どうやって使うのかがよくわからないという方も多いのではないでしょうか。

この記事では、Pythonに標準で付いている `venv` を使って、仮想環境を作る方法をわかりやすく解説します。

## 仮想環境とは？

仮想環境とは、プロジェクトごとに独立したPythonの実行環境のことです。

Pythonでは、`pip install` でさまざまなライブラリ（パッケージ）をインストールできます。しかし、すべてのライブラリをパソコン全体に入れてしまうと、次のような問題が起こります。

- プロジェクトAではライブラリのバージョン1.0が必要なのに、プロジェクトBではバージョン2.0が必要
- どのプロジェクトでどのライブラリを使っているのかわからなくなる
- 不要なライブラリがどんどんたまっていく

仮想環境を使えば、プロジェクトごとに必要なライブラリだけを入れることができるので、こうした問題を防げます。

## venvで仮想環境を作る

### 1. プロジェクトのフォルダに移動する

まずは、ターミナル（Windowsの場合はコマンドプロンプトやPowerShell）を開き、プロジェクトのフォルダに移動します。

```bash
cd my-project
```

### 2. 仮想環境を作成する

次のコマンドで仮想環境を作成します。

```bash
python -m venv .venv
```

`.venv` の部分は仮想環境のフォルダ名です。好きな名前を付けられますが、`.venv` や `venv` とするのが一般的です。

※ macOSやLinuxでは、`python` の代わりに `python3` と入力する必要がある場合があります。

### 3. 仮想環境を有効にする

作成した仮想環境を使うには、「有効化（アクティベート）」する必要があります。

**macOS / Linuxの場合**

```bash
source .venv/bin/activate
```

**Windowsの場合（コマンドプロンプト）**

```bat
.venv\Scripts\activate
```

**Windowsの場合（PowerShell）**

```powershell
.venv\Scripts\Activate.ps1
```

有効化に成功すると、ターミナルの行頭に `(.venv)` のように仮想環境の名前が表示されます。

### 4. ライブラリをインストールする

仮想環境が有効になっている状態で `pip install` を実行すると、ライブラリはこの仮想環境の中だけにインストールされます。

```bash
pip install requests
```

### 5. 仮想環境を終了する

作業が終わったら、次のコマンドで仮想環境を無効にできます。

```bash
deactivate
```

## 使っているライブラリを記録しておく

仮想環境にインストールしたライブラリの一覧は、次のコマンドでファイルに書き出せます。

```bash
pip freeze > requirements.txt
```

別のパソコンで同じ環境を作りたいときは、仮想環境を作って有効化したあと、次のコマンドを実行するだけです。

```bash
pip install -r requirements.txt
```

チームで開発するときや、パソコンを買い替えたときにとても便利なので、ぜひ覚えておきましょう。

## よくあるつまずきポイント

### PowerShellで「スクリプトの実行が無効」と表示される

Windowsの PowerShell では、セキュリティの設定により `Activate.ps1` が実行できないことがあります。その場合は、次のコマンドで現在のユーザーに対して実行を許可してください。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 仮想環境のフォルダはGitに含めない

`.venv` フォルダには大量のファイルが含まれるため、Gitで管理する必要はありません。`.gitignore` に次の1行を追加しておきましょう。

```
.venv/
```

代わりに `requirements.txt` をGitで管理しておけば、いつでも同じ環境を再現できます。

## まとめ

- 仮想環境を使うと、プロジェクトごとに独立したライブラリの環境を作れる
- `python -m venv .venv` で作成し、`activate` で有効化する
- `pip freeze > requirements.txt` で使っているライブラリを記録しておく

最初は少し面倒に感じるかもしれませんが、慣れてしまえば数秒でできる作業です。新しいプロジェクトを始めるときは、まず仮想環境を作る習慣をつけておきましょう！
