# 機種変更の前にやっておきたい、iPhoneのバックアップのとり方

そろそろ新しいiPhoneに変えようかな、という人向けに、バックアップのとり方をざっくりまとめておきます。むずかしくないので、機種変更の前日あたりにサクッとやっておきましょう。

## まずはiCloudでとるのがラク

いちばん手軽なのは、iCloudにバックアップする方法です。Wi-Fiにつながっていれば、パソコンがなくてもできます。

1. 「設定」アプリを開く
2. いちばん上の自分の名前をタップ
3. 「iCloud」→「iCloudバックアップ」をタップ
4. 「今すぐバックアップを作成」をタップ

あとは終わるまで待つだけ。写真が多いと、けっこう時間がかかります。寝る前に充電しながらやっておくのがおすすめです。

## 容量が足りないときは

ここでよくあるのが「iCloudの容量が足りません」と出るパターン。無料の5GBだと、だいたい足りません。

選択肢は2つです。

- iCloudの容量を一時的に増やす（月130円の50GBプランから選べます）。機種変更が終わったら元に戻してもOK
- パソコンにバックアップする

ちなみに、機種変更のときだけ、iCloudの容量が一時的に無料で増える仕組みもあります。「設定」→「一般」→「転送またはiPhoneをリセット」から「開始」をタップすると案内が出るので、使えそうなら使ってみてください。

## パソコンでとる場合

Macなら Finder、Windowsなら「Appleデバイス」アプリ（またはiTunes）を使います。

1. iPhoneをケーブルでパソコンにつなぐ
2. 画面にiPhoneが表示されたら選ぶ
3. 「iPhone内のすべてのデータをこのMacにバックアップ」を選ぶ
4. 「ローカルバックアップを暗号化」にチェックを入れる
5. 「今すぐバックアップ」をクリック

4の暗号化は、地味だけど大事です。これにチェックを入れないと、パスワードやヘルスケアのデータがバックアップされません。設定したパスワードは忘れないようにメモしておきましょう。

## LINEは別でバックアップが必要

忘れがちなのがLINEのトーク履歴。iPhoneのバックアップとは別に、LINEアプリの中でバックアップをとる必要があります。

「ホーム」→ 右上の歯車 →「トークのバックアップ」→「今すぐバックアップ」

これを忘れると、新しいiPhoneでトークが全部消えてしまうので要注意です。

## チェックリスト

最後に、機種変更前にやることをまとめておきます。

- iCloud かパソコンでバックアップをとった
- LINE のトークをバックアップした
- 二段階認証のアプリ（Google Authenticatorなど）の引き継ぎ方法を確認した
- Suica や PayPay の残高の移し方を確認した

ここまでできていれば、だいたい大丈夫です。新しいiPhone、楽しんでください！
