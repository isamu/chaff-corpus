# PDFが重くてメールで送れないときの対処法

「添付ファイルが大きすぎます」と言われて、PDFが送れない。そんなときの対処法を、手軽なものから順に書いていきます。

## そもそも、なぜ重いのか

PDFが重くなる原因の多くは、中に入っている画像です。スキャナーで高い解像度のまま読み取った書類や、スマートフォンで撮った写真を貼った資料は、数十MBになることもあります。

なので、画像を軽くすれば、たいていは解決します。

## 方法1：Macの「プレビュー」を使う

Macを使っているなら、最初から入っている「プレビュー」アプリで軽くできます。

1. PDFをプレビューで開く
2. メニューの「ファイル」→「書き出す」を選ぶ
3. 「Quartzフィルタ」で「Reduce File Size」を選んで保存

ただ、この方法は画質がかなり落ちることがあります。細かい文字が読めなくなっていないか、保存したあとに必ず開いて確認してください。

## 方法2：Adobe Acrobat を使う

会社でAcrobat（有料版）が使えるなら、これがいちばん確実です。

1. PDFをAcrobatで開く
2. 「ファイル」→「その他の形式で保存」→「サイズが縮小されたPDF」を選ぶ

画質と容量のバランスがよく、文字もつぶれにくいです。

## 方法3：オンラインの圧縮サービスを使う

ブラウザでPDFをアップロードするだけで圧縮してくれるサービスもあります。インストール不要で便利です。

ただし、社外のサーバーにファイルを送ることになります。契約書や個人情報が入った書類には使わないでください。会社によっては、使用自体が禁止されていることもあります。

## 方法4：圧縮せずに送る

どうしても軽くならないときは、圧縮をあきらめて、別の方法で渡すのも手です。

- 社内で使っているファイル共有サービス（Googleドライブ、OneDrive、Boxなど）にアップロードして、リンクを送る
- PDFをいくつかに分けて、複数のメールで送る

相手がファイル共有サービスを使えない会社の場合もあるので、事前に確認しておくと安心です。

## 次から重くしないために

スキャンするときは、解像度を200〜300dpi程度にしておくと、読みやすさを保ったままファイルを小さくできます。複合機の初期設定が600dpiになっていることもあるので、一度確認してみてください。
