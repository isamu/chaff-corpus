# Excelからスプレッドシートに移ってわかった、つまずきやすい5つのこと

会社でExcelをやめて、Googleスプレッドシートに切り替えることになった。そんな方に向けて、実際に移ってみてつまずきやすいところを5つまとめました。パソコンにそれほど詳しくない方でも読めるように、なるべく専門用語を使わずに書いています。

## 1. 「保存」ボタンがない

最初にとまどうのがこれです。スプレッドシートには、Excelのような「保存」ボタンがありません。入力した内容は、その場で自動的に保存されます。

画面の上のほうに「ドライブに保存しました」と表示されていれば、保存は完了しています。「保存しないまま閉じてしまった」という心配はいりません。

逆に言うと、間違えて消してしまった内容も、すぐに保存されてしまいます。そんなときは「ファイル」→「変更履歴」→「変更履歴を表示」を開くと、過去の状態に戻せます。これは覚えておくと安心です。

## 2. 同じファイルを何人も同時に開ける

Excelでは、誰かがファイルを開いていると「読み取り専用」になって編集できないことがありました。スプレッドシートでは、何人でも同時に開いて、同時に編集できます。

ほかの人が編集しているセルには、その人の名前と色のついた枠が表示されます。同じセルを同時に書きかえるとややこしくなるので、担当する範囲を決めておくのがおすすめです。

## 3. 関数はだいたい同じ、でも一部ちがう

SUM、AVERAGE、IF、VLOOKUPなど、よく使う関数はExcelと同じように使えます。ふだんの集計で困ることはほとんどないはずです。

ただ、Excelのマクロ（VBA）はそのままでは動きません。マクロを使っているファイルがある場合は、移行の前に社内の担当者に相談してください。

## 4. ファイルの「場所」の考え方がちがう

Excelでは、ファイルはパソコンや社内サーバーのフォルダに保存していました。スプレッドシートは、Googleドライブという「インターネット上の置き場所」に保存されます。

ファイルを人に渡すときも、メールに添付するのではなく、「共有」ボタンから相手を指定する形になります。このとき、相手に「閲覧者」「閲覧者（コメント可）」「編集者」のどれを付けるかを選べます。中身を書きかえてほしくない相手には「閲覧者」を選びましょう。

## 5. 印刷はひと手間かかる

Excelに比べると、印刷のレイアウト調整は少し苦手です。印刷する前に「ファイル」→「印刷」でプレビューを確認し、「用紙に合わせる」や余白の設定を見直してください。

毎回きれいに印刷したい書類は、一度PDFにしてから印刷すると、レイアウトが崩れにくくなります。

## おわりに

慣れるまでは、Excelとのちがいに戸惑うこともあると思います。ただ、自動保存や同時編集は、慣れてしまうと手放せない便利さです。わからないことがあれば、ひとりで悩まず、まわりの人に気軽に聞いてみてください。
