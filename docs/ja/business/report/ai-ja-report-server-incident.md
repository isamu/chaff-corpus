# 障害報告書：社内ファイルサーバーへの接続障害について

報告日：2026年10月21日
報告者：情報システム部 〇〇

## 1. 障害の概要

2026年10月20日（火）9時05分から11時40分までの約2時間35分、本社の社内ファイルサーバー（FS01）に接続できない状態が発生しました。対象は本社に勤務する全従業員（約180名）です。在宅勤務者もVPN経由で同様に接続できませんでした。

## 2. 影響範囲

- 共有フォルダ上のファイルの閲覧・編集ができませんでした。
- 経理部の月次締め作業が約2時間遅れました。
- データの消失・破損は確認されていません。

## 3. 経緯

| 時刻 | 内容 |
|---|---|
| 9:05 | 複数の部署からファイルサーバーにつながらないとの問い合わせ |
| 9:20 | 情報システム部で調査開始。サーバー本体は起動していることを確認 |
| 10:10 | 前日夜に適用したOSの更新プログラムにより、ネットワーク設定が初期化されていたことを特定 |
| 11:15 | ネットワーク設定を復旧し、動作確認を開始 |
| 11:40 | 全部署で接続できることを確認し、復旧を社内に通知 |

## 4. 原因

10月19日（月）22時に自動適用されたOSの更新プログラムにより、FS01のネットワーク設定（固定IPアドレス）が初期化され、DHCPによる自動取得に切り替わっていました。そのため、従業員のパソコンに登録されていた接続先のアドレスとサーバーのアドレスが一致しなくなりました。

更新プログラムの適用前に、検証環境での事前確認を行っていなかったことが、直接の原因を見逃した要因です。

## 5. 対応

- ネットワーク設定を手動で元に戻し、固定IPアドレスを再設定しました。
- 同じ更新プログラムが適用された他のサーバー2台についても設定を確認し、問題がないことを確認しました。

## 6. 再発防止策

1. 更新プログラムの自動適用を停止し、検証環境で確認したうえで手動適用する運用に変更します（10月末までに実施）。
2. サーバーのネットワーク設定に変更があった場合に、情報システム部へ通知が届く監視設定を追加します（11月中旬までに実施）。
3. 障害発生時の社内向け連絡手順を見直し、最初の問い合わせから30分以内に全社へ状況を通知することを目標とします。
