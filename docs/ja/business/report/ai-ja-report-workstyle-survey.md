# 2026年度 働き方アンケート 結果報告

## 1. 調査の概要

- 実施期間：2026年〇月〇日〜〇月〇日
- 対象：全従業員
- 回答者数：212名（回答率81%）

## 2. 主な結果

### 在宅勤務への満足度

在宅勤務に「満足している」と回答した人は78%で、前年度から6ポイント上昇しました。通勤時間の削減や、集中して作業できる時間が増えたことを評価する声が多く寄せられています。在宅勤務の制度や環境が、社内に定着してきていることがうかがえます。

### 部署間の連携

一方で、「部署間の連携が取りにくい」と回答した人は41%にのぼりました。自由記述では、「他部署の誰に聞けばよいかわからない」「ちょっとした相談がしにくくなった」といった意見が目立ちました。

### 会議の量

「会議が多すぎる」と回答した人は35%でした。特に、目的がはっきりしない定例会議や、参加者が多く発言の機会が少ない会議について、見直しを求める声がありました。

## 3. 考察

在宅勤務の満足度が上がった一方で、4割を超える人が部署間の連携に課題を感じています。在宅勤務によって個人の業務は進めやすくなったものの、部署をまたいだ情報共有や、気軽な相談の機会が減っている可能性があります。

また、会議が多いと感じている人が3分の1以上いることから、連携不足を会議の数で補おうとしている面もあると考えられます。会議を増やすのではなく、情報共有の仕組みそのものを見直すことが重要です。

## 4. 今後の対応（案）

- **部署間の窓口の明確化**：各部署の担当業務と問い合わせ先を一覧にし、社内ポータルで公開する
- **チャットツールの活用**：部署をまたいだ相談用のチャンネルを設け、気軽に質問できる場をつくる
- **会議の見直し**：定例会議の目的と参加者を各部署で棚卸しし、不要な会議は廃止または短縮する
