# 市民のノーベル化学賞受賞を祝しての市長コメント

ページID：0044155 更新日：2026年10月8日更新 印刷ページ表示

志木市在住で東京理科大学名誉教授である※合憲三（※石ヘンに夾）＝そあい・けんそう＝先生が、2026年ノーベル化学賞を受賞されました。
世界的に権威のある賞の受賞に際し、香川市長からのお祝いのコメントを掲載します。

## 市長コメント

このたびのノーベル化学賞のご受賞、誠におめでとうございます。
市民を代表して、心よりお祝い申し上げます。

突然の嬉しい知らせに、私自身、大変驚くとともに、この上ない喜びを感じております。
本市の市民の方が、世界で最も権威ある賞の一つであるノーベル賞を受賞されたことは、私たち市民にとって大きな誇りであり、未来を担う子どもたちにとっても、大きな夢と希望を与えてくださるものです。

これまで長年にわたり研究に取り組まれ、世界的な成果を挙げられたことに、心から敬意を表します。

今回のご受賞を心よりお祝いするとともに、今後益々のご活躍とご健勝をお祈り申し上げます。

令和8年10月7日
志木市長 香川 武文
